# Script rules

Every rule here comes from a script a real creator rejected, and why. Apply all
of them before showing a script. Rules the person adds live in
`contenido/reglas.md` and override these.

## 1. Never invent

- **Facts:** every number, study, date, name or claim is searched and verified
  before it goes in, and the source goes on screen in small type ("BLS, EE. UU.,
  2023"). No source → no number; stay general.
- **Lived experience:** never write "it happened to me on the bus" unless the
  person said so. Personal slots are written as **[TÚ: what is needed]** and
  asked with options ("which of these do you compare yourself with, really?").
  The person confirms; only confirmed details stay.
- **Brand claims:** only what is in `marca.md` as verified.

## 2. Identification + value + interaction (all three, every time)

A script that only describes a feeling comes back as "short, flat, no value, no
reason to comment". Each script needs:

- **Identification:** one concrete scene the viewer recognises as theirs
  ("you open Instagram on a Sunday night and everyone seems ahead"). Concrete
  beats abstract; a specific detail is proof someone lived it.
- **Value:** something the viewer leaves with — a verified fact that changes the
  frame, a named concept, or an exercise they can do today.
- **Interaction:** a CTA the viewer can do in two seconds.

## 3. CTAs never ask for anything personal

Good: "tag a friend who needs to hear this", "comment if it happens to you
too", "share it if you relate", "send it to the person who …" (sends weigh the
most in Instagram's ranking), "follow for part 2" in a series.

Bad: "tell me your story in the comments", "comment what you're struggling
with". Personal things are private; don't ask for them in public.

For businesses, a keyword CTA ("comment GUIDE and I'll send it") works when
there is something real to send.

## 4. No silences, ever

- Dialogue is continuous. No pauses for chapter cards, no "beat" of silence.
- Chapter titles and key-number cards are **overlays that appear while the
  person keeps talking** (title top, subtitles bottom).
- Moving between blocks is done with a **spoken bridge** ("and the funny thing
  is…", "and here's what calmed me down…"), a vocal change of pace, and in the
  edit with a digital punch-in or a support shot — never a gap in the audio.
- The person records **one continuous take**, 2–3 full passes; if they stumble
  they carry on with the next line. The edit removes dead air and stumbles.

## 5. Length follows the structure

- Essay / explainer with hook + 3 blocks + value + CTA: **50–60 s**
  (~160–180 spoken words at 160–180 wpm).
- Text-on-loop, meme, list-to-save: 7–15 s.
- A 35-second essay was rejected as "super short". Don't compress value away.

## 6. Structure that worked

```
Hook (0–3 s)      a question or statement that names the viewer's situation
Identification    one concrete scene, first or second person
Block I           title overlay (a question) + the first idea
Block II          title overlay + the tension / the comparison / the myth
Block III         title overlay + the reframe, with a sourced fact
Value             the exercise or takeaway, said as an instruction
CTA               tag / comment if / share if
Signature         the brand's recurring close (e.g. a line in parentheses)
```

Series get a small permanent tag on screen (`name · 01`) and the episode is
titled with its key question.

## 7. Hooks — templates from references that overperformed

Never copy the sentence; use the shape.

| Shape | Example from the reference set |
|---|---|
| Identity question | "¿Quién me conoce mejor, yo o las personas que llevan años conmigo?" |
| Contrary instruction | "Tienes que victimizarte más." |
| Distinction thesis | "There is a difference between artistic cockiness and assertiveness." |
| "You hate X because nobody told you Y" | "You hate networking because nobody ever told you what to do after hi." |
| Hang on a trend | "5 cosas peores que las batallas de aura." |
| Conditional expert | "Si quisiera que mi siguiente oferta sea un sold-out, ajustaría esto." |
| News + promise | "Google acaba de cambiar las reglas… quédate que te cuento." |
| Collective observation | "Everyone's Instagram is starting to look the same." |
| Paradox | "Si quieres amar a alguien toda la vida, tienes que enamorarte varias veces de la misma persona." |
| Accusation with care (you) | "Dices que tienes potencial, pero yo creo que solo te gusta la idea de sentirte especial." |
| Observing strangers | "¿Alguna vez has pensado qué tan grande tiene que ser el dolor de alguien para llorar en el metro?" |
| Audience filter | "Si tienes entre 15 y 32 años y te sientes perdido, mira esto." |
| Mantra / pilot | "No sé cómo lo voy a hacer, pero lo voy a hacer." |

The hook is said **and** written in the first second (text on screen).

## 8. De-AI pass (run before delivering)

Run the `humanizer` skill if installed. Either way, check for these — they are
what made scripts come back as "robotic, generated with AI":

- **"No es X, es Y" / "no se trata de X sino de Y"** used for weight. State Y.
  (A creator's own reframe at the very end can keep it once.)
- **One-line closers** that repeat the point: "La aventura era eso."
- **Forced threes:** three examples in a row when two carry it.
- **Chains of fragments:** "Sin miedo. Sin prisa. Sin excusas."
- **Coach vocabulary:** tu mejor versión, sanar, suelta, fluye, vibra, el
  universo, empodérate, zona de confort, todo pasa por algo, mindset.
- **Staged openers:** "Hablemos de…", "Aquí va la verdad:", "Spoiler:".
- **Instagram formulas:** "Guárdalo para después", "Te leo en comentarios",
  "Aquí nadie juzga".
- Read it aloud as a WhatsApp voice note. If it sounds like a press release,
  rewrite it.

## 9. Shareability test (before approving)

1. Who would you send this to? No name → it won't be sent.
2. What would you write when sending it ("jajaja tú", "esto")?
3. Would you repost it on your own profile?
4. Is there a detail nobody else would have written?
5. Does it work muted, with only the on-screen text?

Background on why people share (STEPPS, benign-violation humor, formats that
get sent): `sharing-psychology.md`.
