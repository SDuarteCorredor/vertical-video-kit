# Adaptation card (replicating a reference)

"Replicating is the best way to use a format without leaving the brand's
thread." The person brings or picks a reference; you break it down; you write
this card; they approve; they film; it gets edited. **Copy the shape, never the
script or the footage.**

```markdown
## <series name> · <nn> · "<episode question/title>"
**Replicates:** @account — "<its hook>" (<link>)
**Topic:** <topic> · **<length> s** · <aspect> · <location>

### What is copied (the shape)
- <how it opens>
- <block structure / chapters>
- <A-roll + B-roll pattern>
- <graphic devices>
- <colour/light>
- <how it closes>

### What changes
Topic, voice, length, format, location — and why.

### Script (continuous, no pauses; overlays in brackets are NOT spoken)
> [hook]
> …
> [overlay top: I · QUESTION]
> spoken bridge + block I…
> …
> [value: fact with source / exercise]
> [CTA: tag / comment if / share if]
> (signature)

[TÚ] slots listed here with the options to confirm.

### Shot list
- **A-roll:** position, framing, camera height, light (key + practical in frame),
  mic in hand, HDR off, exposure lock. One continuous take, 2–3 passes.
- **B-roll** (5–8 s each), each tied to the line it covers:
  1. …

### Graphics (made in the edit)
- Series tag, chapter overlays (style), key-number card with source, card to
  save, subtitles (style/position), cut-outs and where they come from, music.

### Assets to find
- Images (source + licence), data (source link), music (library).
```

Before delivering: facts verified with links, [TÚ] slots asked with options,
de-AI pass done, shareability test passed, no silences anywhere.
